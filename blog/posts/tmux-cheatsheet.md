嵌入式开发经常要 SSH 到服务器/开发板干活,最怕的事:干到一半网络断了,一切重来。tmux 解决的就是这个——**会话挂在后台,断开重连现场还在**。而且窗口/窗格管理让一块屏幕同时干多件事。

## 核心概念:三层结构

```
tmux 会话(Session)  ← 一个工作区,可命名,可挂起恢复
  └── 窗口(Window)  ← 相当于标签页
        └── 窗格(Pane) ← 相当于屏幕分割
```

所有快捷键以 `Ctrl-b` 为前缀(记为 `<C-b>`)。

## 会话:重连不丢现场

```bash
tmux                    # 启动新会话
tmux new -s work        # 命名会话
tmux ls                 # 列出所有会话
tmux a                  # 附加到最近会话(attach)
tmux a -t work          # 附加到指定会话
tmux kill-session -t work   # 结束会话
```

会话内操作:

| 快捷键 | 作用 |
| --- | --- |
| `<C-b> d` | 分离会话(回到终端,后台继续跑) |
| `<C-b> s` | 会话列表(可视化切换) |

**经典流程**:SSH 上服务器 → `tmux new -s build` 跑编译 → `<C-b> d` 分离 → 断线/关终端 → 下次 SSH → `tmux a` 看结果。**编译一直在跑,现场原封不动。**

## 窗口:终端里的标签页

| 快捷键 | 作用 |
| --- | --- |
| `<C-b> c` | 创建新窗口 |
| `<C-b> N` | 跳到第 N 个窗口 |
| `<C-b> p` / `<C-b> n` | 上一个 / 下一个窗口 |
| `<C-b> ,` | 重命名窗口 |
| `<C-b> w` | 窗口列表 |
| `<C-d>` | 关闭窗口(退出 shell) |

## 窗格:一块屏幕多个终端

| 快捷键 | 作用 |
| --- | --- |
| `<C-b> "` | 水平分割(上下两块) |
| `<C-b> %` | 垂直分割(左右两块) |
| `<C-b> 方向键` | 按方向移动焦点 |
| `<C-b> z` | 当前窗格最大化 / 还原(看日志神器) |
| `<C-b> <空格>` | 循环窗格布局 |
| `<C-b> x` | 关闭当前窗格 |
| `<C-b> !` | 把窗格拆成独立窗口 |

典型布局:左窗格 `vim`,右上窗格 `tail -f` 日志,右下窗格跑命令——写代码、看日志、敲命令互不干扰。

## 复制模式与回滚

| 快捷键 | 作用 |
| --- | --- |
| `<C-b> [` | 进入回滚模式(上下翻看历史输出) |
| 翻到目标后 `<空格>` 开始选择 | 选择文本 |
| `<Enter>` | 复制选择(进入粘贴缓冲) |
| `<C-b> ]` | 粘贴 |

编译输出滚过去了?`<C-b> [` 翻回去看,不用重跑。

## 常用配置(~/.tmux.conf)

```bash
# 前缀键改 Ctrl-a(小指友好,不冲突)
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# 鼠标支持(拖拽选窗格、滚轮翻回滚)
set -g mouse on

# 状态栏:显示会话名 + 时间
set -g status-left '#[fg=green]#S '
set -g status-right '#[fg=yellow]%H:%M'

# 窗格分割快捷键简化
bind | split-window -h
bind - split-window -v

# 窗口编号从 1 开始
set -g base-index 1
```

改完配置:``` tmux source-file ~/.tmux.conf ```。

## 进阶:同时操作所有窗格

```bash
<C-b> setw synchronize-panes on   # 同步输入:一个窗格打字,所有窗格同时执行
<C-b> setw synchronize-panes off  # 关闭
```

批量改多台机器配置、多窗口执行同一命令时极其好用。

## 速记口诀

- **断线不怕**:`tmux` 起会话,`<C-b> d` 分离,回来 `tmux a`;
- **屏幕不够**:`<C-b> %` 分左右,`<C-b> "` 分上下,`<C-b> z` 看细节;
- **输出跑了**:`<C-b> [` 回滚翻历史;
- **多机同操作**:`synchronize-panes on`。

> 和 Vim 配合是嵌入式开发的经典组合:Vim 管文件,tmux 管会话,SSH 管连接——三个工具各司其职,一个终端走天下。
