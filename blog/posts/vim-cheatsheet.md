Vim 的学习曲线陡,是因为命令密度高;但一旦上手,它就是最高效的文本编辑器。这篇是**速查手册**,按功能分组,捡最常用的写——记不住的打开这篇查一眼就行。

## 模式

Vim 的模式是核心概念:普通模式(默认)、插入模式(`i` 进入)、可视化模式(`v`)、命令行模式(`:`)。

| 操作 | 命令 |
| --- | --- |
| 进入插入模式 | `i`(光标前)/ `a`(光标后) |
| 上方/下方插入新行 | `O` / `o` |
| 返回普通模式 | `Esc` 或 `Ctrl-[` |
| 进入命令行 | `:`(如 `:w` 保存、`:q` 退出、`:wq` 保存退出、`:q!` 强制退出) |

## 移动

### 基础移动

| 命令 | 作用 |
| --- | --- |
| `hjkl` | 左 / 下 / 上 / 右 |
| `w` / `b` / `e` | 下一个词首 / 上一个词首 / 词尾 |
| `0` / `^` / `$` | 行首 / 第一个非空格字符 / 行尾 |
| `H` / `M` / `L` | 屏幕首行 / 中间 / 底部 |
| `Ctrl-u` / `Ctrl-d` | 上翻半屏 / 下翻半屏 |
| `gg` / `G` | 文件头 / 文件尾 |
| `:{行号}` 或 `{行号}G` | 跳到指定行 |
| `%` | 跳到匹配的括号、`/* */` 等 |
| `f{字符}` / `F{字符}` | 本行向后/向前找字符(`;` `,` 继续导航) |
| `t{字符}` / `T{字符}` | 本行找字符并停在它前面 |
| `/正则` | 搜索,`n` / `N` 下一个/上一个 |

### 计数:命令前面加数字

| 命令 | 作用 |
| --- | --- |
| `3w` | 向后移动三个词 |
| `5j` | 向下移动 5 行 |
| `7dw` | 删除 7 个词 |

## 编辑

| 命令 | 作用 |
| --- | --- |
| `d{移动}` | 删除(如 `dw` 删词、`d$` 删到行尾、`d0` 删到行首、`dd` 删整行) |
| `c{移动}` | 改变(删除并进入插入,如 `cw` 改词、`cc` 改整行) |
| `x` | 删除字符(=`dl`) |
| `s` | 替换字符(=`xi`) |
| `u` / `Ctrl-r` | 撤销 / 重做 |
| `y` / `yy` | 复制(`yank`)/ 复制整行 |
| `p` / `P` | 粘贴到后 / 粘贴到前 |
| `~` | 切换字符大小写 |
| `.` | 重复上一次修改 |

## 可视化模式

| 命令 | 作用 |
| --- | --- |
| `v` | 字符可视化 |
| `V` | 行可视化 |
| `Ctrl-v` | 块可视化(列编辑) |
| 选中后 `d` / `c` / `y` | 删除 / 改变 / 复制选中内容 |

块可视化典型用法:选中多行首列 → `I` → 输入内容 → `Esc`,批量加注释前缀。

## 查找替换

```
:s/旧/新/          当前行第一个
:s/旧/新/g         当前行全部
:%s/旧/新/g        全文件替换
:%s/旧/新/gc       全文件替换,逐个确认
```

## 多窗口与多文件

| 命令 | 作用 |
| --- | --- |
| `:sp` / `:vsp` | 水平 / 垂直分割窗口 |
| `Ctrl-w` + `hjkl` | 在窗口间移动焦点 |
| `:e 文件` | 打开文件 |
| `:bn` / `:bp` | 下一个 / 上一个缓冲区 |
| `:ls` | 列出缓冲区 |

## 宏:重复一组操作

| 命令 | 作用 |
| --- | --- |
| `q{字符}` | 开始录制到寄存器(如 `qa`) |
| `q` | 停止录制 |
| `@{字符}` | 重放宏(如 `@a`) |
| `100@a` | 重放 100 次 |

典型场景:对 100 行做同样修改——录一次,`100@a` 搞定。

## 常用配置

```vim
set number          " 显示行号
set relativenumber  " 相对行号(配合 d5j 这类操作)
set expandtab tabstop=4 shiftwidth=4  " 空格代替 Tab
set hlsearch incsearch     " 搜索高亮 + 增量搜索
set ignorecase smartcase   " 搜索忽略大小写(有大小写时除外)
syntax on
```

## NeoVim + 文件树插件(nvim-tree)

用 NeoVim 的话,文件树操作(你的配置):

| 操作 | 按键 |
| --- | --- |
| 折叠/展开目录、打开文件 | `h` 折叠 / `l` 打开 |
| 在文件树中上下移动 | `j` / `k` |
| 显示/隐藏文件树 | `Ctrl-/`(命令行)或快捷键 |
| 隐藏/显示隐藏文件 | `Shift-h` |
| 向左/向右切换文件标签 | `Shift-h` / `Shift-l` |
| 关闭当前文件 | `空格 + b + d` |
| 退出 | `:qa` |

## 速记口诀

- **移动靠词,编辑靠动词+移动**:`d` + `w` = 删词,`c` + `$` = 改到行尾;
- **改错了别慌**:`u` 撤销,`Ctrl-r` 重做;
- **重复劳动用宏**,多行批量改先用 `Ctrl-v` 块操作。
