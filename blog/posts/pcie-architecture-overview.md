做嵌入式或驱动开发,总会和 PCIe 打交道——它是如今服务器、PC、工控机上事实标准的高速互连总线。这篇文章从"为什么要有 PCIe"讲起,梳理它的分层架构,把三层协议各自的职责讲清楚。

## 为什么 PCI 会走到尽头

PCI(Peripheral Component Interconnect)是 PCIe 的前身,一个**并行共享总线**。它的困境,一句话就能概括:**频率提不上去**。

- 32/64 位并行信号线在 PCB 上等长布线,信号到达各设备的时间必须对齐——频率越高,时序裕量越小;
- 共享总线意味着所有设备挂在同一组线上,仲裁、等待,效率低下;
- 并行线之间的串扰(crosstalk)随着频率上升急剧恶化。

PCI 总线在 33MHz / 66MHz 上足够好,但想再往上走,物理上就是一道墙。

## PCIe 的答案:串行差分 + 点对点

PCIe 把问题拆开解决:

| 维度 | PCI | PCIe |
| --- | --- | --- |
| 信号方式 | 并行共享 | 串行差分(每个 lane 两对差分线) |
| 拓扑 | 共享总线,一主多从 | 点对点连接,设备独占通道 |
| 带宽扩展 | 加宽总线(32→64bit) | 增加 lane 数量(x1/x4/x8/x16) |
| 时钟 | 同步时钟 | 内嵌时钟(从数据中恢复) |

差分信号天生抗共模干扰,串行传输没有并行线的对齐问题,所以每一代都能把速率往上翻:

| 代际 | 速率(每 lane) | 编码 |
| --- | --- | --- |
| Gen1 | 2.5 GT/s | 8b/10b |
| Gen2 | 5 GT/s | 8b/10b |
| Gen3 | 8 GT/s | 128b/130b |
| Gen4 | 16 GT/s | 128b/130b |
| Gen5 | 32 GT/s | 128b/130b |

## 分层协议:三个层,各司其职

PCIe 把复杂度分层,这是它设计上最漂亮的地方。从下到上:

### 物理层(Physical Layer)

把逻辑数据变成电信号。

- 负责**分帧**:识别一个包的边界;
- 负责**编码**:Gen1/2 用 8b/10b,Gen3 起用 128b/130b,保证信号有足够的跳变沿用于时钟恢复;
- 负责**加扰(scrambling)**:避免链路上出现长串的连续 0 或 1;
- 负责**串行化**:把并行的逻辑数据逐 bit 送到差分线上。

### 数据链路层(Data Link Layer)

数据传输的"安全卫士",在物理链路上提供可靠传输。

- 给每个数据包(即 TLP)附加 **12bit 序列号** 和 **32bit LCRC 校验**;
- 发送端保留包副本,没收到 **Ack** 前不删除(重传缓冲区);
- 收到 **Nak** 或超时,自动重发,**上层软件完全感知不到**——这是"可靠性"的关键:错误恢复对软件透明。

### 事务层(Transaction Layer)

面向软件的层,负责"表达意图"。

- 把 CPU 的读写请求组装成 **TLP(Transaction Layer Packet)**,统一了数据、控制、错误报告、中断等所有信息的表达;
- 支持 **posted / non-posted** 两种事务:写内存可以"发完就忘",读内存必须"等回执"(完成包);
- 负责流量控制、事务排序等高层管理。

## 一个数据包的生命周期

从 CPU 视角看一次读请求,数据包是这样"套娃"的:

```
发送方向:
事务层   把"我想读地址 X"装进 TLP 包头
数据链路层 给 TLP 加序列号 + LCRC,副本存入重传缓冲
物理层   编码、加扰、分帧,变成差分信号发出去

接收方向:
物理层   恢复电信号,解码、去扰、定帧
数据链路层 校验 LCRC、核对序列号,发 Ack 确认
事务层   打开 TLP,解读请求,准备完成包
```

链路层和物理层的细节对事务层完全透明——事务层不知道也不关心对端跑的是 Gen3 还是 Gen5、物理介质是什么。这就是**解耦**的价值:每一层只关心自己的契约。

## 核心价值:解耦

回到开头的问题:PCIe 为什么要这么设计?

1. **演进独立**:物理层换更快的编码(128b/130b、更高速率),事务层完全不用动;协议从 x1 扩到 x16,软件接口不变;
2. **可靠与高效分离**:数据链路层用重传机制保证可靠,事务层用 posted/non-posted 和分离事务保证效率——两者互不拖累;
3. **软件友好**:错误恢复、重传都在硬件里完成,驱动只需要面对干净的读/写语义。

理解 PCIe,最重要的不是背寄存器,而是建立这张分层地图。后面我会分别深入数据链路层(序列号/LCRC/重传机制的细节)和事务层(TLP 结构、路由规则、4KB 边界),把这层的协议细节展开讲。
